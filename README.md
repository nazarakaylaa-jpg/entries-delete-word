# The Word You'd Delete From the Dictionary

Entry for the make.fun competition [The Word You'd Delete From the Dictionary](https://make.fun/c/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2).

`main.ts` (Node 22, TypeScript, no network) scores candidate words against the
judge's brief — instant joke, humour from the word itself, freshness — and
writes the winner to `/output/entry.txt`:

> **colonel**

Pronounced "kernel" and spelled nothing like it. Delete it and the most
absurd spelling in the English language goes with it. The obvious pick
("moist") and the grammar pet peeves ("irregardless", "literally") were
scored and rejected; "queue" is kept as the runner-up.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
